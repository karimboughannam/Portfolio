# Karim Boughannam - Portfolio Website

A modern, interactive, and recruiter-friendly portfolio website showcasing my experience as a Quality Assurance Analyst.

## 🚀 Features

- **Modern Design**: Clean, professional UI with smooth animations
- **Responsive**: Works perfectly on all devices (desktop, tablet, mobile)
- **Interactive**: Typing effect, floating cards, particle background, animated profile image
- **Projects Showcase**: Featured QA tools and systems (QA Central, Test Management System)
- **Tools & Technologies**: Visual display of all tools and technologies used
- **Downloadable Resume**: One-click resume download for recruiters
- **Easy to Navigate**: Smooth scrolling and intuitive navigation
- **Contact Cards**: Interactive contact cards with direct links
- **Performance**: Fast loading and optimized for best user experience

## 🛠️ Technologies Used

- **Backend**: Python (Flask)
- **Frontend**: HTML5, CSS3, JavaScript
- **Icons**: Font Awesome
- **Fonts**: Google Fonts (Poppins)

## 📦 Installation

1. **Install Python dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Run the application:**
   ```bash
   python app.py
   ```

3. **Open your browser and visit:**
   ```
   http://localhost:5000
   ```

## 📸 Adding Your Content

### Profile Image
1. Place your professional photo in `static/images/profile.jpg`
2. Recommended: 500x500 pixels, square format
3. Use a clear, professional headshot with good lighting

### Resume
1. Place your PDF resume in `static/resume/Karim_Boughannam_Resume.pdf`
2. Ensure it's up to date with your latest experience
3. Keep file size under 5MB for optimal performance

## 🎨 Customization

You can easily customize the portfolio by editing the `portfolio_data` dictionary in `app.py`. Update:

- Personal information
- Skills
- Work experience
- Education
- Certifications

## 🌐 Deployment

This portfolio can be deployed to various platforms:

- **Heroku**: Add a `Procfile` and deploy
- **PythonAnywhere**: Upload files and configure WSGI
- **AWS/Azure**: Deploy using their app services
- **Vercel/Netlify**: For static deployment
